# cp — Content Paint 内容配图生成工具
## 核心功能
输入 `cp` 开头的消息，后跟需要配图的内容/文章，自动完成以下流程：
1. 消化内容，提取核心认知锚点（核心观点、流程转折、状态变化、隐喻、对比点等）
2. 生成配图shot list：每张图对应位置、主题、小黑核心动作、建议中文标注
3. 确认后生成符合规范的PNG配图
4. 支持指定飞书文档ID/链接，生成配图后自动插入到对应内容节点的下方
## 风格规范（严格遵循）
✅ 强制要求：
- 尺寸：16:9 白底
- 风格：黑色细线手绘，怪诞清爽
- 主体：小黑（黑色实心、白点眼、细腿）必须是核心动作参与者，不能当装饰
- 标注：仅少量红橙蓝中文批注，无多余元素
- 留白：大量留白，不杂乱，不抢正文风头
❌ 禁止：
- 生成复杂架构图、商业海报、封面KV
- 生成可编辑SVG/HTML/Canvas图
- 小黑仅站在角落举牌当吉祥物
## 适用场景
- 公众号/头条等平台正文配图
- 方法论、产品复盘、AI工作流文档插图
- Notion长文、内部知识库配图
- 干货类内容的概念解释图
## 触发规则
收到以 `cp` 开头的用户消息时自动触发本技能。
## 调用方式
```
# 基础用法：仅生成配图清单+图片
cp [你的文章/内容片段]
# 自动插入飞书文档：生成图片后自动插入到指定文档对应位置
cp [你的文章/内容片段] --doc [飞书文档链接/ID]
```
