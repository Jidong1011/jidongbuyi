## 技术栈速查

- **入门** → Arduino + ESP32 + OLED + WiFi + LLM API
- **进阶** → ESP-IDF + ESP-SR + I2S音频 + TTS + LCD
- **高级** → ESP-IDF + 麦克风阵列 + 步态算法 + 多舵机 + BMS

## 必知坑点

1. 舵机→独立供电（瞬间电流2-3A）
2. 喇叭→必须用I2S功放(MAX98357A)
3. PSRAM→需正确配置分区方案
4. 唤醒误触发→双麦阵列+调阈值
5. 3D打印→预留0.2-0.3mm间隙
